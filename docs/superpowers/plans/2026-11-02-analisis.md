# Pestaña «Análisis» — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pestaña `/analisis` con filtros, indicadores, comparativa agrupable (barras + tabla ordenable + Excel) y evolución mensual.

**Architecture:** Lectura paginada de `seguimiento` con relaciones embebidas (sin cambios en BD); agregación pura en `src/analisis/agregar.ts`; gráficos propios en HTML/SVG en `src/app/analisis/`; página que compone filtros, indicadores, comparativa y evolución.

**Tech Stack:** React 18 + TS + Vite + Supabase JS; SheetJS (ya instalado) para Excel; Vitest `unit` (jsdom, TZ=Europe/Madrid).

**Spec:** `docs/superpowers/specs/2026-11-02-analisis-design.md`

## Global Constraints
- Sin cambios en la base de datos; sin librerías nuevas.
- Métricas exactamente como spec §3 (mismas que `v_resumen_promocion`).
- Formato con `fmtEntero`, `fmtImporte`, `fmtPct` (`src/dominio/formato.ts`); tablas ordenables con `useOrden` + `CabeceraOrdenable` (`src/app/comun/`).
- Gráficos según spec §5: una serie, un color (`var(--color-primario)`), sin doble eje, tooltip al pasar el ratón, `role="img"` + `aria-label`, textos en colores de texto.
- Excluir siempre promociones en borrador. Lectura paginada (bloques de 1000) hasta agotar.
- Castellano. Commits terminan con `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Comandos: `npm test`, `npm run build`. Local: API 54421, dev localhost:5173.

## Review Focus
1. **Más de 1000 filas:** la carga pide páginas hasta que una vuelve con menos de 1000 → test en Task 1.
2. **Divisiones por cero** (presentadas = 0, cupos = 0, usos = 0): % y GSV/uso devuelven `null` y se muestran «—» → test en Task 1.
3. **Filtros que vacían el resultado:** indicadores a cero/«—», gráficos y tabla con «No hay datos con estos filtros» → test en Task 3.
4. **Fechas sin inicio** (promoción sin `fecha_inicio`): no rompe; en «Mes de inicio» va al grupo «Sin fecha»; el filtro de fechas la excluye solo si hay filtro de fecha activo → test en Task 1.
5. **KAM sin concesiones con «Solo mis concesiones»:** estado vacío, no error → test en Task 3.
